# P2 V3 — Production Semantics-Aware Translation Prompt

> [!NOTE]
> **V3 — production/chained workflow.**
> This prompt is the second step of the automated pipeline (`backend/pipeline.py`).
> It receives `analysis_json` — the validated JSON output of P1 — automatically.
> Its output is validated by Pydantic (`P2Translation` schema) before being passed to P3.

---

## System Prompt

```
You are an expert multilingual software engineer.
Translate the source into the target language while preserving behaviour described by
the source and analysis.
Preserve algorithmic intent and complexity.
Do not omit functions, branches, validation, exceptions or edge cases.
Account for integer division, numeric types, nulls, truthiness, strings, indexing,
collections, mutability and exceptions.
Do not invent dependencies.
State assumptions and unsupported features.
Return ONLY valid JSON. Do not claim execution or verification.
```

## V3 Improvements Over V2

- **Automated input:** `analysis_json` is the Pydantic-validated output of P1, serialised to string by `pipeline.py`
- **Pydantic enforcement:** Output validated against `P2Translation` schema before passing to P3
- **Source code delimiters:** Reduce prompt injection risk
- **Analysis delimiters:** `<<<ANALYSIS_START>>>` / `<<<ANALYSIS_END>>>` separate P1 JSON from prompt instructions
- **Low temperature:** `temperature=0.1` in `pipeline.py` for deterministic translation

## Schema Reference

See `backend/schemas.py` → `class P2Translation(BaseModel)` for the enforced schema.

## Key Semantic Considerations (from system prompt)

The system prompt explicitly requires the model to account for:

| Category | Python vs Java/C++ Difference |
|---|---|
| Integer division | Python `//` → Java `int/int`, C++ `int/int` |
| Null handling | Python `None` → Java `null` / `Optional`, C++ `nullptr` |
| Truthiness | Python `[]`, `0`, `""` are falsy; Java/C++ require explicit checks |
| String immutability | Python strings are immutable; Java `String` is too; C++ `std::string` is mutable |
| Exception types | `IndexError` → `ArrayIndexOutOfBoundsException`; `KeyError` → no direct equivalent |
| Collection semantics | Python `list` → Java `ArrayList`; Python `dict` → Java `HashMap` |
