# P1 V1 — Baseline Static Analysis Prompt

> [!NOTE]
> **V1 baseline — intentionally simple for comparison. No structured output.**
> This version has no explicit role assignment, no JSON schema constraints, and no chaining.
> It exists to demonstrate what a naive prompt produces versus V2 and V3.

---

## System Prompt

```
You are a helpful programming assistant.
```

---

## User Prompt

```
Analyse the following {{source_language}} code. Describe what it does, what functions it contains, what inputs it expects, what it returns, and any edge cases or potential issues.

Source Language: {{source_language}}

Source Code:
{{source_code}}
```

---

## Expected Output (V1)

Free-form prose description. No guaranteed structure. No schema enforcement.

**Example output shape (illustrative):**
> "This Python function takes an integer n and returns its factorial recursively. It handles n=0 as a base case. Edge cases include negative inputs, which are not handled."

---

## V1 Limitations (Documented for Comparison)

- No explicit role framing (model may not behave consistently)
- No JSON output — not machine-parseable for chaining
- No explicit instruction to flag unsupported constructs
- No instruction to separate observations from assumptions
- Cannot be fed directly into P2 as structured context
- Output quality and coverage is highly variable across runs
