# P2 V1 — Baseline Translation Prompt

> [!NOTE]
> **V1 baseline — intentionally simple for comparison. No structured output.**
> This version does not use P1's output as context. It is a standalone "translate this code" prompt.
> It exists to demonstrate what a naive translation prompt produces versus V2 and V3.

---

## System Prompt

```
You are a helpful programming assistant.
```

---

## User Prompt

```
Translate the following {{source_language}} code to {{target_language}}. Make sure the translation is correct and preserves the original behaviour.

Source Language: {{source_language}}
Target Language: {{target_language}}

Source Code:
{{source_code}}

Provide the translated code below:
```

---

## Expected Output (V1)

Translated code as plain text (no JSON wrapper, no assumption list, no notes).

**Example output shape (illustrative):**
> "Here is the Java translation: [code block]"

---

## V1 Limitations (Documented for Comparison)

- No role framing — model may not reason carefully about semantic differences
- No use of P1 analysis — does not know about edge cases identified in analysis
- No assumptions field — assumptions are silent
- No instruction to flag unsupported constructs
- No JSON output — cannot be fed into P3
- "Preserves the original behaviour" instruction is vague and unverifiable
- May silently translate integer division incorrectly (e.g. Python `7//2` → Java `7.0/2`)
- Output is not schema-enforced; structure varies between runs
