## [0.1.0] — 2026-11-22

### Added

- Initial project scaffold (Milestone 2)
- FastAPI backend with P1→P2→P3→P4 pipeline
- React+Vite+TypeScript frontend
- Prompt library V1, V2, V3
- 10 test cases (CB-T01 to CB-T10)
- Project documentation (PROJECT_FACTS, MILESTONE_STATUS, BUILD_LOG)
- `.gitignore` and `.env.example`
- `scripts/run_dev.ps1` — one-command dev server launcher (Windows)
- `scripts/check_secrets.ps1` — secret scanning for tracked files
- `scripts/run_tests.py` — offline and live test runner
- Pydantic v2 schemas for all 4 pipeline stages
- CORS configuration for local development
- `/health` endpoint for backend liveness checks
- Swagger UI at `/docs` (auto-generated by FastAPI)
